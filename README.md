# Attendance.work

HR, attendance and payroll software for teams in Nepal.

Website: https://www.attendance.work

## Features
- Staff check in from their phone with location saved
- Leave requests, holidays and shifts
- Late and overtime reports
- Payroll with SSF and EPF calculation
- Payslips sent by email
- 14-day free trial for new companies
